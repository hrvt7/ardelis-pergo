# Mérce (bar) – ellenőrizhető mechanizmusok a referenciákból (TrainerFlow, Kiwi; Ádám képei, 2026-11-16)

1. A hérón a termék valódi felületének legalább 3 darabja (UI-kártya) látszik lebegve, valódi adatokkal (ár, lépés, lead), a fő vizuál körül, eltérő mélységben.
2. Egy alap (#ECECEF / fehér lap) + egy hangos hang (Vanilla #EFF0A3): a Vanilla képernyőnként legfeljebb 3 helyen, mindig kijelölésként vagy kiemelésként.
3. A címsor ≈ 3–4× a törzsszöveg mérete, legfeljebb 3 sor; a kiemelt szó alatt Vanilla aláfestés.
4. Ritmus: világos szakasz – egy sötét (ink) szakasz termék-UI-val – világos szakasz.
5. A funkciókártyákon nem ikon, hanem kis élő vonalrajz-jelenet (vonalas fekete körvonal, pasztell kitöltés), kártyánként eltérő méretben (nem egyforma rács).
6. A záró CTA mögött vonalrajz-csempék rácsa, a cím egy elmosott sávon áll, élesen.
7. Képernyőnként ≈ 40–50% üres tér; fő CTA (fekete pill) minden képernyőnyi szakaszban elérhető.
